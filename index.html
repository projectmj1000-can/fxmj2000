How it works

모든 거래는 다섯 단계를 거칩니다

  1. 시장 감시

    주요 통화쌍 실시간 호가 수신. 연결 끊김 시 자동 복구.

  2. 신호 생성

    캔들 마감마다 전략별 매수·매도 신호 산출.

  3. 리스크 심사

    손실 한도, 경제지표, 스프레드 조건을 통과한 신호만 채택.

  4. 주문 집행

    손절 주문을 브로커 서버에 동시 등록. 시스템 중단 시에도 보호.

  5. 기록·보고

    체결·청산 즉시 알림. 모든 판단 근거 저장.
